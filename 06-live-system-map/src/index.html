В центре — остров с ядром: это сама модель Claude, она работает в облаке Anthropic. Вокруг пролива — город на твоём ПК: приложение D.A.V.E., программа Claude Code (кольцевая развязка), инструменты, память, навыки, агенты и подключённые модули. Единственная переправа между ними — мост API. Светящиеся точки на дорогах — данные, которые прямо сейчас ездят по каналам.

Насколько это точно
Подтверждено — кварталы, дороги и путь сообщения: так реально устроены D.A.V.E. и Claude Code на этом ПК, все здания взяты из моей текущей конфигурации.
Условно — внутренность ядра. Это общая схема трансформера: сколько у меня слоёв и параметров, Anthropic не публикует, а свои веса я изнутри не вижу.
